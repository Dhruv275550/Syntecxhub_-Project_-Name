Expense Tracker

A responsive expense tracker application built using React.js and Vite. It allows users to add, view, search, and delete expenses while managing expense data efficiently.

Features

- Add new expenses
- View all expenses
- Search expenses by title
- Filter expenses by category
- Delete expenses
- Display total expenses
- Responsive user interface
- Fast development using Vite
- State management using React Hooks

Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- React Hooks
  - "useState"
  - "useEffect"
  - "useMemo"
  - "useCallback"
  - "useRef"

Installation and Setup

1. Clone the repository

git clone https://github.com/your-username/expense-tracker.git

2. Navigate to the project directory

cd expense-tracker

3. Install dependencies

npm install

4. Start the development server

npm run dev

The application will be available at the local URL shown in the terminal.

Available Scripts

Command| Description
"npm run dev"| Starts the development server
"npm run build"| Creates a production build
"npm run preview"| Previews the production build
"npm run lint"| Checks the code for linting issues

How to Use

1. Enter the expense title.
2. Enter the expense amount.
3. Select an expense category.
4. Click Add Expense.
5. View the added expense in the list.
6. Use the search or category filter to find expenses.
7. Delete an expense when it is no longer required.
